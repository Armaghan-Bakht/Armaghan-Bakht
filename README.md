### 💡 Executive Engineering Summary

I operate at the intersection of **modern full-stack web engineering** and **high-performance interactive creative tech**.

While many web developers focus solely on standard CRUD interfaces, my work spans both scalable **Next.js & MERN enterprise web applications** and **ultra-lean HTML5 playable ads** for top-tier ad networks like **AppLovin**, **Mintegral**, **Google Ads**, and **TikTok**. 

This dual discipline demands ruthless performance budgets, 60 FPS animation pipelines, memory leak prevention, and single-file bundling strategies (< 2MB to 5MB total creative budget) — bringing an engineering rigor that elevates every project I build.

### 🧠 Senior Engineering Principles

> **1. Performance is a Core Feature, Not an Afterthought**  
> If an interactive experience stutters or a web page takes more than 2 seconds to become interactive, user trust drops exponentially. Profiling CPU frames, garbage collection pauses, and bundle payloads is fundamental to my delivery process.

> **2. Single-File Discipline Meets Scalable Architecture**  
> Writing games that package 60fps logic, audio, and textures into one single autonomous HTML file teaches a level of resourcefulness and optimization that directly enriches my enterprise Next.js and React codebases.

> **3. Micro-Interactions Drive Conversions**  
> Delight lives in the nuances: smooth gesture physics, tactile feedback, crisp state transitions, and responsive typography that feel alive under the user's fingertips.
